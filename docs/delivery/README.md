# Delivery Documentation

Public-facing technical companion docs for the Payments Dispute Resolution accelerator.

This folder intentionally keeps **implementation-focused material only**. Internal discovery, sales, and scripted demo collateral is not part of the public OSS package.

- **[5-REUSABLE-CODE.md](assets/5-REUSABLE-CODE.md)** — repo structure, reusable patterns, notable implementation artifacts
- **[6-DEPLOYMENT-GUIDE.md](assets/6-DEPLOYMENT-GUIDE.md)** — setup, configuration, troubleshooting
- **[8-LEARNING-LOG.md](assets/8-LEARNING-LOG.md)** — lessons learned, risks, follow-on improvements
- **[9-TECHNICAL-DEEP-DIVE.md](assets/9-TECHNICAL-DEEP-DIVE.md)** — API, schema, workflows, security, performance, deployment details
