## Key Decisions

1. **Raw resource vs. AVM module** — Chose raw `Microsoft.Web/staticSites` for consistency with existing `ai.bicep` and `functions.bicep`. No network resolution at build time = offline-friendly. Can migrate to AVM later.

2. **Free SKU** — Sufficient for demo (no custom domain, staging, private networking). Upgrade to Standard if SWA EasyAuth or private endpoints needed in hardening phase.

3. **No linked-backend in Bicep** — SWA's `linkedBackend` property omitted. API calls route through Functions (function-level key auth) rather than SWA's built-in proxy. Preserves current auth topology; EasyAuth adoption will require Bicep update + SKU upgrade.

4. **Node 20 pinned** — Prevents implicit runner version changes from breaking Vite builds. LTS through April 2026.
