## Key Decisions

1. **Single `apiFetch<T>` pattern** — Unified mock + live + fallback, no code duplication in components
2. **Types from Keaton's schema** — Direct import from `src/web/src/types/case.ts`, contract alignment guaranteed
3. **WinProbGauge uses plain `<div>`** — Fluent ProgressBar lacks color prop; custom implementation gives full control
4. **Optimistic status update** — POST actions update local state immediately (no re-fetch needed for demo)
5. **Near-deadline threshold: ≤ 3 days** — Consistent red highlighting in queue and detail pages
